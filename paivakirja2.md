# Oppimispäiväkirja: Hajautettu git

__Mikä osion tehtävissä oli vaikeaa ja mikä helppoa? Mikä auttoi minua oppimaan? Miten selvitin esteet, jotka vaikuttivat tehtävän suorittamiseen?__

Tässä Hajautettu git -osiossa tehtävien tekeminen oli mielestäni taas helpompaa kuin silloin, kun tein kurssia ensimmäisen kerran. Tämä osio oli kuitenkin hieman vaikeampi kuin Paikallinen git -osio. Muistan, että myös ensimmäisellä keralla tämä aihe tuntui joistain syystä vähän sekavalta, vaikka tässä on vain yksi harjoitus.

Tällä kertaa tehtävät olivat kuitenkin helpompia, vaikka jouduin välillä edelleen miettimään, mitä seuraavaksi piti tehdä. Etärepositorion ja paikallisen repositorion toiminta sekä new-feat-haara olivat aluksi vähän epäselviä. Opin myös, että GitHubissa voi tehdä muutoksen omalle koneelle. Git fetch oli minulle jo ennestään tuttu komento, mutta tämän tehtävän avulla ymmärsin paremmin, mitä se käytännössä tekee.

Minua auttoivaat tehtävien ohjeet, netissä olevat tiedot ja aikasemmin opitut asiat. 
Käytin taas usein git status -komentoa, koska se auttoi tarkistamaan missä vaiheessa olin ja oliko kaikki kunnossa. Vaikka jotkut kohdat olivat edelleen vähän haastavia, tällä kertaa tiesin paremmin miten selvitän niitä. 

Tämän osion jälkeen tämä aihe ei tunnu enää yhtä sekavalta kuin ensimmäisellä kerralla. En vieläkään muista muista kaikkia komentoja ulkoa, mutta ymmärrän paremmin mitä tehtävässä tapahtuu. 

## Osiossa käyttämäni Git-komennot

| Komento | Kuvaus |
| git fetch | hakee uudet muutokset etärepositoriosta, mutta ei vielä yhdistä niitä omaan haaraan |
| git status | näyttää repositorion tilanteen ja kertoo mitä tiedostoissa on muuttunut |
| git remote -v | tarkistaa etärepositorioasetukset |
| git branch | näyttää repositorion haarat |
| git push   | lähettää paikalliset commitit GitHubiin |
| git merge  | yhdistää yhden haaran muutokset toiseen haaraan |
| git tag    | luon tagin, jolla voidaan merkitä tietty kohta Gitin historiassa |
